# Market Pulse 美股情绪决策

手机优先的情绪决策面板。自有指标沿用 AAII 20%、预估市盈率10%、NAAIM20%、VIX25%、QQQ RSI6 25%的既定规则。第三方定投评分和ETF溢价独立展示。

## 数据与更新

- 正式数据源：`https://uui000718-ai.github.io/us-market-sentiment-app/data/`。
- Sites 通过 `/api/report` 读取；GitHub Pages 版本直接读取相邻的 `data/` 文件。
- 打开、回到前台、网络恢复时重读；停留期间每5分钟检查，1分钟内的重复自动请求合并。
- 分别显示数据生成时间、服务读取时间、行情日期。美国周末和常规节假日按最近完成的交易日判断；提前收盘日保守按16:30美东检查，临时休市需人工核对交易所公告。
- 本次请求成功不代表上游刚抓取。旧行情、盘中行情、过期周度指标分别标记。
- 无真实数据且无本机有效缓存时显示可重试错误，不展示演示投资建议。
- 本机存储不可用或损坏不影响在线读取；离线缓存明确标记。

## 展示

买入决策分为−100到+100。情绪温度是另一指标，置于可展开说明中。缺失值显示破折号，估算数据及未接入维度单独标记。NAAIM超过7天不参与综合判断，AAII及市盈率超过7天停止买入提示。

保留13只场内ETF、默认159501、各基金独立分档、120交易日溢价统计，以及页面底部近180自然日的首次买入信号记录。历史读取已有记录，不回推不存在的触发时点。

新增独立的市场环境观察：QQQE/QQQ、RSP/SPY等权相对表现（20/60个共同交易日切换）、FRED实际利率DFII10和周度金融压力STLFSI4。该模块不改变原权重及邮件触发规则。每项保留观测日期和成功读取时间，来源失败时明确标记保留样本。详见`docs/market-context-research.md`。

## 构建

Sites：使用 Sites 插件的 `build-site.mjs` 和 `site-workflow.mjs` 完成构建和发布。

GitHub Pages：`pnpm exec vite build --config github.vite.config.ts`，产物为 `dist/github/`；将页面和资源同步到现有仓库 `site/`，保留 `site/data/`，由现有工作流更新数据并发布。

验证：`node --test tests/*.test.mjs`（渲染测试需先完成 Sites 构建）。

## 私密邮件通知

由与 Site 关联的私有云任务通过已连接 Gmail 发送。收件路由保存在 Gmail 私密配置草稿中，公开页面、仓库、日志不包含地址。任务按最新自有指标买入事件检查，以已发送邮件中的唯一事件标记去重。首次启用前的旧事件不补发；读取失败、过期或无新信号时不发送。发送结果不明确时先检查已发送记录，不自动重放。

Gmail连接和云任务必须保持启用。网页打开时不发送邮件，也不持有Gmail访问权限。
