# Market Pulse 美股情绪 APP

公开访问地址：<https://uui000718-ai.github.io/us-market-sentiment-app/>

项目每天通过 GitHub Actions 抓取 AAII、纳斯达克100预估市盈率、NAAIM、VIX、QQQ RSI 和 CFTC 机构仓位，生成 `site/data/latest.json` 并发布到 GitHub Pages。

## 自动更新时间

- 工作日北京时间约 06:47
- 工作日北京时间约 08:17（备用更新）
- 也可以在 Actions 页面手动运行

GitHub 定时任务可能延迟数分钟。网页每次打开和点击刷新按钮时都会重新读取最新数据。

## 手机安装

- iPhone：使用 Safari 打开，点击分享按钮，选择“添加到主屏幕”
- Android：使用 Chrome 打开，在菜单中选择“安装应用”
